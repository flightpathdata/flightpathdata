## Release Cadence

FlightPath Data releases every two to three months on average. Each release includes the latest FlightPath Server and, of course, the most current CsvPath Framework release. CsvPath Framework releases more frequently, typically monthly, but sometimes more rapidly. All releases are backwards compatible, unless otherwise noted. Incompatible change happens very rarely.

## Other Sources

You can also learn about release on [csvpath.org]([https://www.csvpath.org/modes](https://www.csvpath.org/topics/release-notes)). CsvPath Framework releases are primarily covered there and we cross-post FlightPath release notes. For CsvPath Validation Language, also checkout the [CsvPath Github repo](https://github.com/csvpath/csvpath). And the Help tab in FlightPath Data provides another cut of the same information.
