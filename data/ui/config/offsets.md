# 🔰 The Offsets Form
{: .no_toc }




## Temporarily off-setting the date
![](/assets/app_images/offsets.png)
<div>The offsets form</div>
{: .caption }
1. <b>Offsets</b>. During testing, you may want to set the system time to a certain point or range in order to see how your validations perform. These offset fields let you add or subtract days, months, and years from the actual current date.
1. <b>Now</b>. The system's understanding of the current moment is shown in this field.
