#  The Dialogs

The FlightPath UI is minimalistic, conventional, and focused on developer DX. Virtually everything you need to build effective preboarding automation is within one or two clicks.

{: .note}
For deeper dives into working within FlightPath Data, see the [How-tos section](/data/examples.html).

{: .important}
Within the Config Panel, the [Server Form](/data/ui/config/server.html) also includes a small number of dialogs that act as a window into remote projects.

<script>
  document.addEventListener("DOMContentLoaded", function () {
    document.querySelectorAll(".nav-list-link").forEach(function (link) {
      if (link.textContent.trim() === "FlightPath Data") {
        link.closest(".nav-list-item").classList.add("active");
      }
    });
    document.querySelectorAll(".nav-list-link").forEach(function (link) {
      if (link.textContent.trim() === "FlightPath Server") {
        link.closest(".nav-list-item").classList.add("active");
      }
    });
  });
</script>
