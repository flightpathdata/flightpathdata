#   The FlightPath Data UI: The Config Forms
{: .no_toc }

### FlightPath Data's config panel helps you organize projects productively
{: .no_toc }


A FlightPath project is just a CsvPath Framework project that lives in FlightPath Data's projects directory or an API key's directory on FlightPath Server. That is to say, a project is primarily the values in a config.ini file. The config forms help you organize your project quickly with minimal need to know your way around a config.ini file.


<script>

      }
