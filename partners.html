Working With Industry Standards For Edge Data Governance.

Lineage Tracking

OpenLineage

The open framework for data lineage collection and analysis

Data lineage is the foundation for a new generation of powerful, context-aware data tools and best practices. OpenLineage enables consistent collection of lineage metadata, creating a deeper understanding of how data is produced and used.

With FlightPath
FlightPath Data and FlightPath Server are native OpenLineage event producers. Every run, stage, validation load, and error generates events to connect your upstream Edge Data Governance with your downstream data consumers. The data preboarding ingestion process becomes transparent in real-time and historically.

Enterprise Observability

OpenTelemetry

The industry standard for monitoring, metrics and alerting

OpenTelemetry is the open source observability framework for cloud native software. It pipes distributed traces and metrics from event producers like FlightPath Server to over 80 enterprise observability platforms, including New Relic, Grafana, DataDog, OpenObserve, and more.

With FlightPath
FlightPath Data and FlightPath Server emit DataOps OpenTelemetry events natively. OpenTelemetry instruments every data ingestion step, giving you the ability to visualize, monitor, and alert in real-time.
